# Analysis Output Framework

This project now treats pooled-analysis inputs as curated artifacts rather than
whatever files happen to be present in `sites/analysis`.

## Directory Layout

`analysis_ready/` is the concise, auditable workspace for downstream analysis.
It is generated by `code/post_processing/00_build_analysis_manifest.R`.

- `analysis_ready/manifest.csv`: one row per curated input file.
- `analysis_ready/site_inputs/`: copied canonical site-level inputs grouped by
  family.
- `analysis_ready/pooled/tables/`: pooled-analysis outputs generated from the
  manifest.
- `analysis_ready/pooled/figures/`: pooled figures generated from the manifest.

The original `sites/`, `output_10082025/`, and copied analysis files are not
deleted or modified by the organizer. The manifest records the original source
path, curated path, site, family, pollutant/outcome when available, active flag,
and MD5 checksum.

## Manifest Rules

Downstream pooled code should only read files where:

- `active == TRUE`
- `exists == TRUE`
- the requested `family` matches the analysis input family

This prevents accidental inclusion of Finder copy files, older reruns, and
ad hoc intermediate exports.

## Current Families

- `cif_plotdf`: per-site cumulative incidence curves.
- `cif_bins`: per-site exposure-bin definitions for CIF curves.
- `model_cumulative`: cumulative PM2.5/NO2 site model tidy outputs.
- `model_subtype`: NO2 by ARF subtype model tidy outputs.
- `finegray_shr`: site Fine-Gray SHR exports.
- `site_summary`: ARF summary exports.
- `missingness`: site missingness exports.
- `county_counts`: county-year ARF counts.
- `table1`: table 1 source exports.

## Regeneration

Run:

```sh
Rscript code/post_processing/00_build_analysis_manifest.R
Rscript code/post_processing/03_pooled_analysis_manifest.R
```

The first script rebuilds `analysis_ready/manifest.csv` and copies curated
inputs. The second script regenerates pooled tables and figures only from the
manifest.
